# Repository Agent Guide

This is the canonical entry point for humans and AI coding agents working in
`NoteBooks`. Read this file before changing the repository.

## Repository purpose

Wright State University MIS 3820 supplementary lab/exercise notebooks Jason maintains as the instructor.

## Ownership

Ownership: Wright State University coursework. Jason owns and maintains this
repository as the instructor; treat student-submitted content (datasets,
notebooks) as student work product, not Jason's personal IP, when relevant.

## Start here

1. Read [README.md](README.md) for what this repository actually contains.
2. This is course material, not a shipped software product — most changes
   here are maintenance (updating for a new term, fixing a broken notebook
   dependency), not feature development. Prefer minimal, verifiable changes.

## Sources of truth

- Course materials live in this repository, near the content.
- Cross-repository/business coordination lives on Jason's scrum board, not in
  this file. A reference between the two is a relationship, not a
  synchronized state — never assume one side reflects the other without
  checking.
